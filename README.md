# arraylib

Кроссплатформенная динамическая библиотека операций над массивами целых чисел. Лабораторная работа № 2 по дисциплине «Алгоритмизация и программирование».

## Функции

- `arr_sum` — сумма элементов;
- `arr_max`, `arr_min` — максимальный и минимальный элементы;
- `arr_average` — среднее арифметическое;
- `arr_count_positive`, `arr_count_negative`, `arr_count_zero` — количество положительных, отрицательных и нулевых элементов;
- `arr_product` — произведение элементов;
- `arr_median` — медиана.

## Сборка и тесты

    cmake -S . -B build
    cmake --build build -j
    cd build && ctest --output-on-failure
